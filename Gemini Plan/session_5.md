## Session 5: Streamlit Multi-Tab Dashboard & Future Partner Tab

### Objective
Build a clean, interactive Streamlit multi-tab user interface for managing uploads, viewing charts, and tracking shared balances.

### Tasks
1. Build **Tab 1 (Overview Dashboard):** Monthly spending graphs, category breakdown charts (using Plotly or Streamlit native charts), and summary financial health metrics.
2. Build **Tab 2 (Statement Upload Center):** Drag-and-drop file uploader supporting multiple PDFs and XMLs with instant preview and auto-tagging options.
3. Build **Tab 3 (Shared Expenses Ledger):** Filterable table of shared costs, split adjustments, and the live "Amount Partner Owes Me" counter.
4. Prepare architecture for **Tab 4 (Partner's Finances - Future Optimization):** Add a structural placeholder or toggle to separate your partner's uploaded statements for reverse balance calculation.

### Prompt for Claude Code (Session 5)
> "Build the complete multi-tab Streamlit frontend in `app.py`. Include: Tab 1 for an Overview Dashboard with spending graphs and category breakdowns; Tab 2 for a Statement Upload Center supporting batch PDF and XML uploads with preview tables; Tab 3 for a Shared Expenses Ledger showing live balance calculations ('Amount Partner Owes Me'); and a structural placeholder Tab 4 for future partner finance isolation."
